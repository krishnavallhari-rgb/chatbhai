# Premium Social Chat Platform — Short PRD (Frontend-Focused)

**Stack:** Next.js (App Router), React, TypeScript, Tailwind CSS, Lucide Icons, Framer Motion.
**Backend:** Skipped for now — use mock/dummy data.

**Design:** Minimal, modern, premium (Instagram + Telegram + Discord + Apple Messages + Notion inspired, not a copy). Inter font, rounded corners, soft shadows, glass effects, micro-animations, no childish colors.

**Palette:** BG `#F8FAFC` · Card `#FFFFFF` · Text `#111827` · Muted `#6B7280` · Border `#E5E7EB` · Primary `#2563EB` · Hover `#1D4ED8` · Light Blue `#60A5FA` · Success `#22C55E` · Danger `#EF4444` · Warning `#F59E0B` · Bubble Mine `#2563EB` · Bubble Other `#F3F4F6`
